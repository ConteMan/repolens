# 投放归因与广告收入数据流

买量渠道负责把用户带进 App，[广告聚合](term:mediation)平台负责决定用户在 App 内看到哪家广告源的广告。
两者产生的数据分属不同事实，不能相互替代。

## 归因

[MMP](term:mmp) 在渠道之外独立判断用户归属，并把 App 内产生的价值信号回传给各渠道。
未被任何渠道归因的用户计为 [Organic](term:organic)。

## 对账

聚合平台的收入与归因平台看到的收入存在差异是正常现象。核对时先统一口径，再比较数值。
