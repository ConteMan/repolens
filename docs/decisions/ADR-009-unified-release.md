# ADR-009 CLI 和桌面端统一版本

状态：已接受。扩展 ADR-008 的平台范围至 Windows x64，并取代桌面首发的独立编号约定。

自 v1.10.0 起，CLI、macOS Universal 和 Windows x64 桌面端由同一提交构建，使用一个 vX.Y.Z 标签、一个 GitHub Release。各端安装包独立。每次发版汇集所有产物后公开。CLI 的 upgrade 和桌面更新器均从这一发布系列读取各自资产。桌面 0.1.0 的用户通过安装包或 Homebrew 一次迁移。

两端共享 Git 来源、配置级联、渲染和静态站点构建。同一份输入应生成相同站点。工作区草稿、输出目录所有权保护、预览监听和 CLI 参数由入口负责。
