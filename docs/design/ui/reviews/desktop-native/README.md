# 原生桌面端第六轮设计

Spec 021 的仓库与规则流程已确认作为首期实现基线。打开仓库后进入站点设置，检查当前有效配置，再进入构建与预览。应用设置在未打开仓库时也可用。版本 1.0.0 和 1.0.1 为更新流程样例。

## 画板编号

画板编号使用短横线连接功能前缀与组内两位序号，例如 `REPO-01`。DS 表示设计系统，CMP 表示共享组件，REPO 表示仓库选择与切换，SITE 表示站点设置，BUILD 表示构建与预览，APP 表示应用设置。新增画板取该组下一个序号，按流程摆放；已有编号可持续用于评审引用。

## 桌面设计系统

[基础与组合画板](EE0xK.png) 定义语义颜色、字号、间距、圆角、按钮状态与固定操作栏。

[控件与状态画板](o7jx3.png) 与业务画板共享组件主件。调整主件可更新其页面实例；页面仅覆盖文案、选中值和可用宽度。

| 元素 | 使用规则 |
|---|---|
| 间距与圆角 | 以 4 px 为基础，图标与文字间隔 8 px，字段水平内距 12 px，页面边距约 40 px。控件圆角 6 px，菜单 8 px，确认对话框 12 px。 |
| 按钮 | 高 36 px，按文案宽度加左右各 14 px。整组图标和文字居中。同组按钮间隔 8 px，确认弹窗操作组距右侧和底部各 24 px。每个任务状态最多突出一个下一步；返回、检查或查看文件夹使用带浅灰描边的次按钮。加载时保留原按钮宽度，禁止重复触发；16 px 指示器约 900 ms 匀速转一圈。启用减少动态效果时使用静态图标和状态文字。 |
| 选择 | 2–4 个互斥且需要比较的选项优先显示单选；独立布尔设置使用复选框。语言等短名单直接展开；代码配色等长名单支持输入过滤和无匹配反馈。方向键移动，Enter 选中，Esc 收起并还原焦点。 |
| 提示 | 齿轮使用应用语言的无障碍名称。指针停留约 500 ms 或键盘聚焦后显示 Tooltip，离开或 Esc 关闭。字段解释使用标签旁的信息图标。提示传达补充信息，校验错误展示在字段旁。 |
| 导航与分隔条 | 选中项使用中性底色和字重。侧栏边界常态 1 px，透明命中区宽 8 px，悬停时加深并显示水平调整指针；键盘聚焦时显示焦点环。 |

## 窗口与导航

21 个业务画板均引用「布局 / 桌面窗口」（S4y4j），页面内容填入主内容插槽。变量 windowTop 同时控制两栏的 48 px 顶部留白，titleRepoGap 控制标题行和仓库选择行之间的 4 px 间距。标题和仓库文字共用 18 px 左边距。

主窗口使用系统窗口按钮和连续背景。空白区可拖动窗口，导航、按钮、文本输入、分隔条分别处理点击、编辑和拖动。侧栏默认 236 px，建议范围 192–340 px；用指针拖动或键盘方向键调整，双击恢复默认。宽度作为应用偏好保存。仓库名称按实际可用宽度中间省略，保留开头与末尾。悬停或键盘聚焦可查看全名，打开仓库菜单可看到完整路径并切换项目。窄窗口优先保留内容区；标签超宽时可横向滚动。

## 仓库选择与恢复

仓库名称、分隔线和导航图标左边缘统一在侧栏内 18 px 处。仅在有工作区导航时显示分隔线。

[首次打开失败](zNZfN.png) 时，在选择页显示刚选的文件夹名、具体原因和「重新选择文件夹」。[切换仓库失败](cNlxd.png) 时，提示固定在仓库选择器下方，保留当前仓库、草稿和导航位置。选择有效仓库后进入正常切换流程。取消或 Esc 收起浮层，将焦点还给仓库选择器。系统文件选择器中的取消属于正常返回。校验错误持续到重选或取消，出现时由辅助技术宣读，焦点移到重选按钮。

## 规则编辑与验收示例

从 [SITE-04 的规则列表](IUxOV.png) 开始，[新增规则](Zm1CB.png) 将 `docs/private/**` 的「生成浏览页」显式设为关闭。加入草稿时追加到末尾；上移一次后，[列表](YLJSz.png) 中它位于 `docs/**` 与 `assets/**` 之间。点击「保存设置」核对[新增内容与最终顺序](tEPcX.png)，返回编辑保留草稿。确认写入后复用 SITE-09 的固定反馈，重新打开时校验规则顺序与显式关闭值。行首和行尾分别禁用上移和下移。跳过浏览页只影响该规则匹配的浏览页生成，镜像与访问权限遵循现有构建合同。

外部配置对应[待选择](Z0IhMH.png)、[已载入](wIy7b.png)、[有修改](RYB4c.png)三种状态。选择文件和编辑草稿均不会写入磁盘。已经有其他标签草稿时，仍按全部实际目标汇总保存。构建结果的时间和来源取自最近一次成功构建的快照；打开预览指向该产物。

## 配置字段与编辑入口

六个标签共用底部操作栏，左侧显示保存目标，右侧「保存设置」与字段右边缘对齐。表单独立滚动，标签和操作栏固定。普通表单行用留白分隔。有修改时启用保存入口。点击后汇总所有标签的草稿，在确认对话框中按目标文件展示差异。点击「确认保存」后写入。涉及多个文件时，操作栏显示目标文件数量，确认对话框中展开具体路径。

[SITE-10 多项与长值](x9NlX.png) 展示跨文件保存确认。单项短值沿用 SITE-07 的行内对照；文件或更改较多、任一值换行时，按文件分组，逐字段上下显示修改前后值。长路径允许在分隔符处及连续字符间软换行，多行值保留原有换行，可复制完整原文。弹窗宽高受窗口可用空间约束；只有差异区滚动，顶部总数和底部操作固定。

编辑期间只更新草稿，已编辑字段失焦时校验。点击「保存设置」时校验全部标签，定位首个错误并保留输入。[字段错误](jrxuG.png) 在控件下说明可接受的值。确认写入成功后关闭弹窗，固定操作栏持续显示带勾的[已保存反馈](Hqzgl.png)和实际目标，直到下一次修改。写入失败或版本冲突时保留草稿并显示原因和恢复操作。应用设置中的版本使用可选中文本，项目主页使用可聚焦的外部链接。

## 应用设置与 Cubbix 回归经验

应用语言支持跟随系统、简体中文、English，保存在用户偏好中。切换时保留编辑草稿、导航位置和构建状态。应用设置单独管理桌面版本、项目仓库链接、手动检查和自动更新。下载完成并验证可安装后显示重启按钮。重启前处理未保存的配置和正在执行的构建。

- Cubbix 的 updates_test.go 覆盖关闭自动更新后手动下载、检查中途关闭开关、重复检查合并和安装失败重试。桌面端沿用这些验收场景，失败时提供可重试的原因。
- Cubbix 的窗口位置测试覆盖显示器断开和窗口最小化恢复。恢复 Repolens 窗口时按当前屏幕可用区域约束位置与尺寸，随后重新计算允许的侧栏宽度。
- Cubbix 的设置窗口修订将更新内容放回设置页。这里同样在应用设置原位呈现检查中、已是最新、可下载、下载中、已就绪及失败状态。中英文按钮分别验收。
