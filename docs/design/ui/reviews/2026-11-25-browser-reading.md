## 已确认的行为

- **语言**。首屏沿用现有 `site.language` 的解析和回退规则，未设置时使用简体中文。切换只影响 Repolens 的界面文案，包括动态提示、无障碍名称和文件属性标签。仓库正文、文件名、链接目标与术语解释取自原始输入。读者偏好按部署 base path 隔离；普通导航、刷新和 PJAX 导航应一致。禁用 JavaScript 时由构建期输出完整的项目默认语言。
- **目录文件**。站点可选自动、展开或折叠。自动模式下，存在可阅读的目录正文时收起文件表，否则展开。原生 disclosure 的整行摘要可用鼠标或键盘操作。条目数量按实际展示列表计算，零条目保留本地化空状态。展开后保留名称、类型、大小、更新时间和原有链接；图中简化了表格列。一次手动折叠只作用于当前页面。
- **布局**。窄栏沿用 72ch，标准沿用主题内容宽度，全宽使用剩余阅读区域。靠左、居中、靠右作用于正文容器。作者选择默认宽度与位置，读者的本地覆盖优先；菜单中的恢复动作清除该站点的布局覆盖。全宽时位置项不可选，回到受限宽度时恢复原选择。旧宽度值 default 对应标准。无 JavaScript 时首屏仍采用作者配置。

实现验收包含同源两个部署子路径、已有英文配置、无 README 的目录、无 JavaScript、PJAX 前进后退、窄屏、高倍缩放和键盘关闭菜单后的焦点恢复。画板用于评审新增控件；既有工具栏的搜索、信息等操作仍须在真实页面验收。阅读偏好与 [Issue 39](https://github.com/ConteMan/repolens/issues/39) 部分重合，本轮只讨论语言、目录文件与布局。
