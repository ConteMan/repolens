# 020 浏览站阅读体验

状态：已实现。关联 M13、005、006、011。

设计与验收以[已冻结的三张画板和行为说明](../design/ui/reviews/2026-11-25-browser-reading.md)为准。范围包括生成站点、配置加载和既有管理界面的配置往返保存。

目录列表、宽度和对齐分别使用 `view.directory-files`、`view.content-width`、`view.content-align`。默认组合为 auto、standard、left，保留原站点的正文宽度与位置。项目语言沿用 `site.language`。目录摘要的数量来自渲染条目。布局与语言覆盖使用按部署路径隔离的浏览器存储。

完成条件为中文和英文首屏及运行时界面、三种目录策略、三档宽度与三种位置均通过冻结稿所列场景。静态站点支持无脚本阅读和目录开合，资源随产物分发。恢复布局默认值保留语言选择。
