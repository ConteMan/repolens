# 022 原生桌面工作区

状态：已实现。接续 [021](021-native-desktop-rules.md)，覆盖 [桌面设计基线](../design/ui/reviews/desktop-native/README.md) 的全部业务页面。

工作区打开仓库后进入基础信息。六个标签可独立编辑所有已支持配置项，共享跨标签草稿和保存确认。共享字段可选择写入仓库或已选外部配置，并按现有配置级联显示有效值和来源。目标切换保留两边草稿。构建者信任域仅写入显式选择的外部配置。修改前后值、写入目标、冲突及成功状态在原位可见。构建与预览读取已保存的配置，未指定输出目录时使用应用缓存。外部配置显式指定的相对输出目录以该配置文件所在目录为基准，自定义输出沿用 Spec 014 的目录归属与替换检查。非空目录缺少 `.repolens-build` 时，提示使用空目录或直接在应用缓存中构建。选择缓存只影响当前桌面会话。预览最近一次成功构建，记录产物来源和时间。

应用设置独立于仓库，保存界面语言、侧栏宽度和自动更新偏好。手动检查、自动检查与下载及重启安装走 MyGo 的签名更新渠道。自动更新开启时，启动检查发现新版本后下载，重启由用户发起。缺少发布资产时显示暂无可用版本，仍可手动检查。恢复窗口时按当前显示器的可用区域约束尺寸和位置。设计中的版本和更新时序为示例。

验收采用与源稿相同尺寸的原生窗口、临时 Git 仓库和真实配置读写，检查 1024 × 632 中文、窄窗英文、保存、构建与预览流程。离屏测试补充边界状态。发布正式更新包另行进行。

工作区正文居中，最大宽度 1000 个逻辑像素。页脚与正文对齐，窄窗收紧水平边距；欢迎页的选目录按钮按文字宽度显示。构建页的来源与输出共用值列，显示实际生效的本地绝对路径；远程来源显示仓库地址和本地镜像目录，指定的 Git 引用和构建者配置独立显示。路径预览不创建目录。

更新渠道尚无桌面版本时，显示中性状态。检查失败和下载失败各自提供重试入口，原始错误可展开查看和复制。
