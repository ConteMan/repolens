# 022 原生桌面工作区

状态：实现中。接续 [021](021-native-desktop-rules.md)，覆盖 [桌面设计基线](../design/ui/reviews/desktop-native/README.md) 的全部业务页面。

工作区打开仓库后进入基础信息。六个标签可独立编辑所有已支持配置项，共享跨标签草稿和保存确认。共享字段可选择写入仓库或已选外部配置，并按现有配置级联显示有效值和来源。目标切换保留两边草稿。构建者信任域仅写入显式选择的外部配置。修改前后值、写入目标、冲突及成功状态在原位可见。构建与预览读取已保存的配置，默认输出应用缓存，自定义输出沿用 Spec 014 的目录归属与替换检查。预览最近一次成功构建，记录产物来源和时间。

应用设置独立于仓库，保存界面语言、侧栏宽度和自动更新偏好。手动检查、自动检查与下载及重启安装走 MyGo 的签名更新渠道。自动更新开启时，启动检查发现新版本后下载，重启由用户发起。缺少发布资产时显示暂无可用版本，仍可手动检查。恢复窗口时按当前显示器的可用区域约束尺寸和位置。设计中的版本和更新时序为示例。

验收采用与源稿相同尺寸的原生窗口、临时 Git 仓库和真实配置读写，检查 1024 × 632 中文、窄窗英文、保存、构建与预览流程。离屏测试补充边界状态。发布正式更新包另行进行。
