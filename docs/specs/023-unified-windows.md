# 023 Windows 桌面端与统一版本

状态：实施中。关联 [ADR-009](../decisions/ADR-009-unified-release.md)。

Windows x64 与 macOS 复用原生工作区、六个设置标签、配置差异确认、本地构建与预览。系统窗口按钮、目录选择器、配置和输出路径依平台处理。Windows 安装包与 macOS 和 CLI 产物共用一个版本号和 Release。桌面更新采用平台对应的签名清单。

自动验收覆盖 Windows 原生编译、含中文和空格的路径、配置保存与构建、回环预览，以及相同仓库和配置经 CLI 与桌面入口构建后的文件对比。候选安装包须在 Windows 交互桌面核对标题栏、缩放、中文输入、目录选择、安装与卸载；升级需区分首次安装与已有版本更新。全部平台通过后发布。
