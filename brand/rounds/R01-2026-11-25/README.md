# Repolens 标志首轮评审

本轮简报来自维护者提出的三个使用场景：“在仓库 README、桌面端、如果之后有官网，都会有用到 Logo 的地方。” Repolens 将 Git 仓库变成可浏览、可发布的静态站点。标志首先要适合与产品名并排，也要能独立出现在 Dock 和浏览器标签页。沿用桌面端强调蓝 #3958BE，深色页头使用反白。

[打开场景对照](index.html)。每个方向提供可编辑 SVG 和 16 px 版本。点击大图可检查 1024 px 轮廓。

| 方向 | 表达 | 首轮观察 |
| --- | --- | --- |
| A 折页 | 从仓库打开一页可读的内容 | 厚书脊与弯曲的右页形成不对称剪影。与常见打开的书相近，右下翻页是辨识点。16 px 版收掉第三片页角。 |
| B 索引 | 页签的高度构成目录层级 | 平直轮廓适合工具属性，外形也容易被读作柱图或文件夹。 |
| C 取景 | 圆形取景面内镂出书签 | 单色反白最稳，和收藏按钮的含义接近。 |

开发工具常用几何轮廓，例如 VS Code 的折带与 Obsidian 的切面晶体。相邻产品中，Cubbix 用橙底深色猫形，Ceave 用红底白色衔草鸟。本轮集中在纸页与索引，保留品牌间的色相和轮廓差异。[VS Code](https://code.visualstudio.com/brand) · [Obsidian](https://obsidian.md/brand)

推荐 **A 折页**。它把发布后的阅读体验放在第一位，侧影还能在小尺寸下保留左右两页。待维护者选定方向，再精修几何与字标间距。
